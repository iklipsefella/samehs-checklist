SAMEH'S CHECKLIST CAPTURE EXTENSION

INSTALL
1. Unzip this folder.
2. Open chrome://extensions in Chrome.
3. Turn on Developer mode.
4. Click Load unpacked.
5. Select this extension folder.
6. Open chrome://extensions/shortcuts to change the hotkey if needed.

USE
1. Highlight text in WhatsApp Web, Slack, Gmail, or any normal webpage.
2. Press Ctrl + Shift + Y on Windows, or Command + Shift + Y on macOS.
3. Sameh's Checklist opens with the text ready to review and save.

The extension also schedules Chrome notifications for reminders synced from the checklist. It does not wake a sleeping or powered-off computer.
